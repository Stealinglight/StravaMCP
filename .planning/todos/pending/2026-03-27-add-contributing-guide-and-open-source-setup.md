## Problem

## Solution

- Set up GitHub issue templates (bug report, feature request)
- Ensure GitHub Issues are enabled on the repo
- Consider adding a CODE_OF_CONDUCT.md
- Add a "Contributing" section to the README (Phase 3)
- Label structure for issues (good first issue, bug, enhancement, etc.)
