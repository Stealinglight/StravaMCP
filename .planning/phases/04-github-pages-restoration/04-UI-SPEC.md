# Phase 4 -- UI Design Contract

> Visual and interaction contract for the GitHub Pages docs site. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase context:** This phase restores a deleted GitHub Actions deployment workflow. No custom UI is built -- the visual contract is entirely inherited from the just-the-docs Jekyll theme with `color_scheme: dark`. This spec documents the rendered contract so the executor and auditor know exactly what to verify once the site is live.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Jekyll theme) |
| Preset | not applicable |
| Component library | just-the-docs v0.12.0 (remote_theme) |
| Icon library | none |
| Font | System UI stack: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif |

Source: `docs/_config.yml` -- `remote_theme: just-the-docs/just-the-docs`, `color_scheme: dark`

## Spacing Scale

Declared values (inherited from just-the-docs `$spacing-unit: 1rem = 16px`):

| Token | Value | Usage |
|-------|-------|-------|
| sp-1 | 4px (0.25rem) | Inline icon gaps, tight padding |
| sp-2 | 8px (0.5rem) | Compact element spacing |
| sp-4 | 16px (1rem) | Default content spacing, paragraph margins |
| sp-5 | 24px (1.5rem) | Section padding |
| sp-6 | 32px (2rem) | Layout gaps, heading top margins |
| sp-8 | 48px (3rem) | Major section breaks |
| sp-10 | 64px (4rem) | Page-level vertical spacing |

Exceptions: none -- all spacing is theme-managed, no custom overrides

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (1rem, $font-size-6) | 400 (regular) | 1.4 (body), 1.6 (content blocks) |
| Label / Small | 14px (0.875rem, $font-size-4) | 400 (regular) | 1.4 |
| Heading (h1) | 32px (2rem, $font-size-8) | 700 (bold) | 1.25 |
| Display (.fs-9) | 42px (2.625rem, $font-size-10) | 700 (bold) | 1.25 |

Monospace: SFMono-Regular, Menlo, Consolas, monospace -- used for code blocks and inline code.

Source: just-the-docs `_variables.scss` -- `$body-line-height: 1.4`, `$content-line-height: 1.6`, `$body-heading-line-height: 1.25`

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #27262b ($grey-dk-300) | Page background, body surface |
| Secondary (30%) | #302d36 ($grey-dk-250) | Sidebar background, nav background, card surfaces, code block containers |
| Accent (10%) | #2c84fa (lightened $blue-000) | Hyperlinks, "Get Started" primary CTA button, search highlights, active nav indicator |
| Destructive | not applicable | No destructive actions in this phase |

Accent reserved for: hyperlinks, `.btn-primary` buttons (the "Get Started" CTA), active navigation state, search result highlights. Never applied to body text, headings, or decorative elements.

Additional theme colors:
- Body text: #e6e1e8 ($grey-lt-300)
- Headings: #f5f6fa ($grey-lt-000)
- Code background: #0d1117 (explicit hex in dark.scss)
- Code line numbers: #e6edf3 (explicit hex in dark.scss)
- Borders: darkened variant of $grey-dk-300

Source: just-the-docs `_sass/color_schemes/dark.scss`

## Interaction Contract

This phase has no custom interactions. All interactions are provided by just-the-docs theme:

| Interaction | Behavior | Verify After Deploy |
|-------------|----------|---------------------|
| "Get Started" button click | Smooth scroll to #quick-start anchor | Yes |
| "View on GitHub" button click | Opens https://github.com/Stealinglight/StravaMCP in same tab | Yes |
| Search | Lunr.js client-side search across all page headings | Yes |
| Copy code button | Copies code block content to clipboard | Yes |
| Back to top | Scrolls to page top when visible | Yes |
| Aux nav links | Open external URLs (GitHub, Strava API, MCP spec) | Yes |
| Responsive layout | Sidebar collapses to hamburger menu on mobile | Yes |

Note: This phase uses no component registries. The Jekyll theme is loaded via `remote_theme` directive from the official just-the-docs GitHub repository. ## Deployment Verification Checklist

These are the visual and interaction properties the executor must verify once the workflow deploys successfully:

1. Site loads at `https://stealinglight.github.io/StravaMCP/` (HTTP 200)
2. Dark color scheme is active (dark background, light text)
3. "StravaMCP" renders at display size (`.fs-9`, ~42px)
4. "Get Started" button is visible and styled as primary (blue accent)
5. "View on GitHub" button is visible and styled as secondary (outline)
6. Tool reference table renders with 5 category rows
7. Code blocks have dark background (#0d1117) with copy button
8. Search icon is visible in header and returns results
9. Footer contains "Built with Go | View on GitHub"
10. No broken links or missing assets in browser console
