**Part A: Add PostMultipart to Strava client**

Add to `internal/strava/client.go`:
```go
// PostMultipart makes an authenticated POST request with a pre-built multipart body.
// The contentType must include the multipart boundary (use writer.FormDataContentType()).
func (c *Client) PostMultipart(ctx context.Context, path string, body io.Reader, contentType string) ([]byte, error) {
    fullURL := c.baseURL + path
    return c.doRequest(ctx, http.MethodPost, fullURL, body, contentType)
}
```

This is a thin wrapper -- `doRequest` already handles auth headers, token refresh, rate limits, and error detection. The key difference from `Post()` is that PostMultipart accepts a pre-built `io.Reader` body and an explicit `contentType` string (with boundary), whereas Post() marshals an interface{} to JSON.

Handler: `handleCreateUpload(client *strava.Client) server.ToolHandlerFunc`:
1. Parse `filePath := mcp.ParseString(request, "file", "")`. If empty, return error "create_upload: file path is required".
2. **D-04 auto-detect data_type from extension:**
   ```go
   dataType := mcp.ParseString(request, "data_type", "")
   if dataType == "" {
       ext := strings.ToLower(strings.TrimPrefix(filepath.Ext(filePath), "."))
       switch ext {
       case "fit", "tcx", "gpx":
           dataType = ext
       case "gz":
           base := strings.TrimSuffix(filePath, ".gz")
           innerExt := strings.ToLower(strings.TrimPrefix(filepath.Ext(base), "."))
           switch innerExt {
           case "fit", "tcx", "gpx":
               dataType = innerExt + ".gz"
           default:
               return mcp.NewToolResultError("create_upload: cannot detect data_type from extension; provide data_type explicitly"), nil
           }
       default:
           return mcp.NewToolResultError("create_upload: unrecognized file extension '" + ext + "'; provide data_type explicitly (fit, tcx, gpx, fit.gz, tcx.gz, gpx.gz)"), nil
       }
   }
   ```
3. **File extension security validation per Pitfall 4:** Before opening the file, validate that the resolved dataType is one of: "fit", "tcx", "gpx", "fit.gz", "tcx.gz", "gpx.gz". This naturally limits which files can be read.
4. Open file: `file, err := os.Open(filePath)`. Handle error with "create_upload: open file: %v".
5. Build multipart form:
   ```go
   var buf bytes.Buffer
   writer := multipart.NewWriter(&buf)
   part, err := writer.CreateFormFile("file", filepath.Base(filePath))
   // handle err
   io.Copy(part, file)
   file.Close()
   writer.WriteField("data_type", dataType)
   ```
6. Add optional form fields from arguments: check `args := request.GetArguments()` for "name", "description", "external_id" (string fields) and "trainer", "commute" (boolean fields as "true"/"false" strings).
   ```go
   for _, field := range []string{"name", "description", "external_id"} {
       if v, ok := args[field]; ok {
           if s, ok := v.(string); ok && s != "" {
               writer.WriteField(field, s)
           }
       }
   }
   for _, field := range []string{"trainer", "commute"} {
       if v, ok := args[field]; ok {
           if b, ok := v.(bool); ok {
               writer.WriteField(field, strconv.FormatBool(b))
           }
       }
   }
   ```
7. Close writer: `writer.Close()` (MUST close before reading buf).
8. Call `client.PostMultipart(ctx, "/uploads", &buf, writer.FormDataContentType())`. **Critical per Pitfall 5:** Use `writer.FormDataContentType()` which includes the boundary. NEVER hardcode "multipart/form-data".
9. Return `formatResponse(data, client)` or `handleToolError("create_upload", err)`.
